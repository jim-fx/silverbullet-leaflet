Embedded [Leaflet](https://leafletjs.com) map for SilverBullet. Renders a `leaflet` fenced code block as an interactive map with markers and polylines.

````markdown
```leaflet
lat: 59.025009
lng: 12.225037
zoom: 10
markers:
  - lat: 59.025009
    lng: 12.225037
    title: Start
```
````

See the [README](https://github.com/jim-fx/silverbullet-leaflet#readme) for all options.
